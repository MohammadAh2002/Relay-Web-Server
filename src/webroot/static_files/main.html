Meet Relay — A Web Server Written in Rust

Relay is a web server built from the ground up in Rust, exploring the fundamentals of networking and HTTP. From handling TCP connections to parsing HTTP requests, this project is about understanding what happens behind the scenes when a browser talks to a server.
